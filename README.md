# Listwell website

Privacy policy, support and landing page for App Store Connect, published with GitHub Pages as `iliescub/listwell-legal` (copy this folder into that repo's root). Generated by `scripts/make_website.py`.
Self-contained: system fonts, no third-party requests; the only script is the inline one on card/ (generated by `scripts/make_card_page.py`), which decodes the card from the link without network requests.
